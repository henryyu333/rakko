# Rakko 使用说明

Rakko 是住在 macOS 刘海里的工具：首页、文件托盘、剪贴板、便利贴、工具卡、AI 用量、Agent 完成提醒和桌面海獭，都从刘海里长出来。平时它完全隐形；悬停或拖拽靠近刘海时先探头提示。

点一下刘海（或按 `⌃⌥Space`）打开的是搜索条，输入就能搜整台 Mac：托盘、剪贴板、便利贴、应用、文件夹、文件和动作。搜索条下方挂着页面胶囊：首页、托盘、剪贴板、工具，打开 AI 用量后还有 AI 用量；点一个页面，它在搜索条原来的位置长出来，440 × 250，所以面板停在菜单栏下面，不会盖住菜单栏和窗口（首页在歌词栏打开时加宽到 640）。如果是拖着东西过来，直接打开「托盘」页等着接收。Esc 一级一级往回退：页面回到搜索条，有输入时先清空输入，再按一次收回刘海。

系统要求：Apple Silicon 芯片（M1 或更新）的 Mac，macOS 13 或以上。不支持 Intel 芯片的 Mac。

## 安装

1. 下载 `Rakko.dmg`（Releases 页面的最新版本）。
2. 打开下载好的文件，把 **Rakko** 拖到 **Applications（应用程序）** 文件夹上。
3. 从“应用程序”里打开 Rakko。它常驻屏幕顶部的菜单栏，不在 Dock 上占图标。
4. 按 **Control + Option + 空格**（`⌃⌥Space`）打开搜索条，也可以单击菜单栏图标或点刘海。

每个版本的 Releases 里也有同一版本的 `Rakko-<version>-macos-arm64.zip`。

### 第一次打开：提示“未打开 Rakko”

Rakko 是免费软件，没有经过 Apple 公证，所以 macOS 会让你确认一次。请只对从本项目 Releases 页面下载的版本这样做。

**macOS 15 或更新**

1. 在“应用程序”里双击 Rakko。系统提示未打开时，点 **完成**（不要点“移到废纸篓”）。
2. 打开 **系统设置 → 隐私与安全性**，往下滚动到 **安全性**。
3. 在“已阻止 Rakko 以保护 Mac”旁边，点 **仍要打开**。
4. 输入开机密码或用触控 ID 确认，再点一次 **仍要打开**。

**macOS 13 或 14**

在“应用程序”里按住 Control 点按（或右键点按）Rakko，选 **打开**，再在弹窗里点 **打开**。

这是只针对 Rakko 的一次性例外，不需要关闭系统安全保护。如果系统提示 App **已损坏**，不要绕过，删掉后重新下载。Apple 官方说明：[在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。

### 系统权限（可选）

设置… → 系统权限 列出三项权限和它们的状态，最后一行是一个开关；也可以右键菜单栏图标 →「开启系统权限（还差 N 项）…」，数字是还差几项。打开开关后，Rakko 按顺序打开系统设置里的三页，你在每页打开 Rakko 的开关后它自动走到下一项：

1. **完整磁盘访问**：从「下载」「桌面」「文稿」或 iCloud 云盘拖文件进来时不再弹窗；下载进度也用它。列表里没有 Rakko 时点 +，或把访达里选中的 Rakko 拖进去。
2. **辅助功能**：刘海拖放保护。拖着东西靠近刘海时，指针停在接收区里，不会顶到屏幕最上沿；拖窗口到刘海分屏也用它。
3. **屏幕录制**：只给「框选文字」用。

最后点「重新打开 Rakko」让授权生效。macOS 要求每一项都由你自己打开；Rakko 不会在启动时申请。

### 卸载

1. 右键菜单栏图标 →「退出 Rakko」。
2. 把“应用程序”里的 Rakko 移到废纸篓。
3. 如果连保存的内容也要删除，删掉 `~/Library/Application Support/Rakko/` 文件夹。

## 从 ShelfU 升级

Rakko 是 ShelfU 的新名字。Rakko 第一次打开时会把数据文件夹整个复制过来：`~/Library/Application Support/ShelfU/` 变成 `~/Library/Application Support/Rakko/`，托盘内容、Rakko 自己保存的图片、转换结果、布局和设置都在，里面指向旧文件夹的绝对路径也会一并改写。它是复制而不是搬移，并且一步到位：失败时两个文件夹都保持原样。旧文件夹完整保留，确认内容都在以后可以删掉。

新文件夹已经存在时不会复制（以新的为准）。ShelfU 还在运行时 Rakko 不会迁移，会提示你先退出它，然后重新打开 Rakko。

macOS 会把 Rakko 当成一个新应用（应用标识变了），所以升级后系统权限和「开机时自动启动」要重新打开一次。

- **在 ShelfU 里应用内更新**：更新装好后，在“应用程序”里打开 ShelfU。它会把应用包改名为 `Rakko.app` 并从那里打开；数据文件夹在那一次启动时复制过来。
- **用 Rakko.dmg 安装**：先退出 ShelfU，把 `ShelfU.app` 移到废纸篓，只让 Rakko 使用你的内容。

从更早的 Shelf 升上来：没有 ShelfU 文件夹时，Rakko 同样从 `Application Support/Shelf/` 复制，也会把 `Shelf.app` 改名。

## 搜索条与页面

**搜索条**：点刘海或按 `⌃⌥Space`，一条黑色搜索条从刘海里长出来，键盘直接进输入框。输入就向 Spotlight 查询整台 Mac，结果面板按 托盘 → 剪贴板 → 便利贴 → 应用 → 文件夹 → 文件 → 动作 的顺序分组，每组最多三行，整张面板装不下时从最后面开始整行去掉。每一行是两行字：上面是名字（图片在最左边显示缩略图），下面是它所在的文件夹、来源应用 · 时间，或者只有时间。`↑`/`↓` 选择，回车打开文件（文字则复制，便利贴则打开它的窗口，动作则执行），`⌘回车` 在 Finder 中显示。面板最后一行是动作条：「打开 ↩」，文件和文件夹、应用这一行还有「在 Finder 中显示 ⌘↩」。输入停下约 80 毫秒才发起查询，旧的查询会被取消，所以快速打字不会问已经打过的词。

**页面**：搜索条下方的胶囊挂着页面和设置、收起。页面在搜索条原来的位置长出来，尺寸 440 × 250，内容区 416 × 174，内容多时在页内滚动；首页占满整页的 200 点高度，歌词栏打开时加宽到 640。当前页面的按钮回到搜索条。

**Esc** 一级一级往回退：页面 → 搜索条 → 清空输入 → 收回刘海。点面板外或再按一次快捷键直接收起。

**焦点**：悬停、拖入和应用切换不抢键盘；打开搜索条时，点击或快捷键都会把键盘交给输入框。面板未取得键盘、且你正在使用它时，会临时持有空格键和 Esc；搜索框取得焦点后，这些键由输入框处理。应用切换只在打开期间临时持有左右键、回车和 Esc，退出后归还。

## 应用切换

点刘海探头右侧、播放中音乐两翼右侧，或导航胶囊里的「应用切换」按钮，展开应用两翼。左侧最多四个固定常用应用，右侧是其他运行中的应用与「更多」；同一个应用不重复显示。刘海中央仍然打开搜索，悬停不会自动展开切换器。

- **切换或启动**：点一个图标切到该应用；固定应用没有运行时会启动。也可用左右键选择、回车切换。切换完成后两翼收起，不会又把焦点切回原应用。
- **编辑常用**：「更多 → 编辑常用应用」，从已安装应用中添加、取消固定，使用「前移 / 后移」调整顺序。最多四个；满额时先取消一个。全部取消后保持空列表，不会重新放回默认应用。
- **已卸载应用**：固定项保留为不可切换的占位，可在编辑列表中移除。
- **收起**：Esc 依次返回编辑列表上一层、关闭「更多」、收起两翼；收起按钮或点外面也可取消。切换期间音乐与短时提示让位，退出后恢复。
- **快捷键**：设置… → 快捷键 →「应用切换」，默认未设置，再按一次可收起切换器。
- **权限与数据**：只切应用，不切窗口或标签页；不需要辅助功能或屏幕录制权限。只在 `settings.json` 的 `pinnedApps` 中保存固定应用标识及顺序，不记录激活历史或使用时长。

## 首页

点胶囊最左边的房子图标进首页。点刘海打开的仍然是搜索条。首页只看此刻；在工具页点音乐卡片本身（不是卡片上的按钮）也能进这里。

- 有歌在放、或者只是暂停着，首页就是播放器：封面、歌名和歌手，播放时右边有跳动的音频条；进度条可以拖动跳转，左边是已经播了多久，右边是还剩多久（前面带负号）；下面一排是上一首 / 播放暂停 / 下一首，左下角是歌词按钮。
- 点左下角的歌词按钮，播放器右边多出一栏歌词，页面从 440 加宽到 640，中间一条竖线隔开。同步歌词在这里滚动，当前一行加粗并居中，越远越淡；先问 lrclib.net，它没有或太忙时再问网易云音乐。找的时候写「正在找歌词…」，没有这首歌的歌词时写「没有找到这首歌的歌词」，取不到时写「歌词暂时取不到」，30 秒后再试。这一栏默认关着，开关记在 `settings.json` 的 `lyrics` 里；只有打开它才会去查歌词，收起后不再联网。
- 没有歌在放时，首页左边是海獭（安静十分钟后打瞌睡），右边是今天的日期和星期，下面最多三行，有内容才出现：最近一轮 agent 正在做还是刚做完（只在打开「Agent 完成提醒」时出现）、托盘里有多少个文件、保持唤醒还剩多久；没有开启保持唤醒时，这一行是剩余最少的那个 AI 额度（AI 用量页关着时不显示）。
- 首页没有方格、不接受拖入、没有编辑模式，也没有音量条：音量在工具页 2×2 的音乐卡片上。

## 托盘

- 把文件、文件夹、图片或文字往刘海拖，刘海提示「松开放入」，还在拖着时「托盘」页就打开了。整页变成投放区：松在「放入托盘」宽格就收进托盘；松在下方的动作格上，就按文件类型直接处理（全是图片：转成 PDF、转 JPEG（全是 JPEG 时是转 PNG）、压缩到 1 MB、隔空投送；全是 PDF：转 Word、每页存成图片、打成 zip、隔空投送；全是压缩包：解压、隔空投送；其他：打成 zip、隔空投送）。结果放进托盘，原文件不动。投放行下沿还会探出海獭的头：文件悬停时它抬起爪子，松手时把文件抱进怀里，然后缩回边缘。
- 文件以缩略图显示，可以一次拖出一个或多个（按住 `⌘` 或 `⇧` 多选）直接拖进任何应用；设置… → 托盘 →「拖出后从托盘移除」可以让拖出去的东西自动离开托盘（置顶的保留）。
- 按空格快速查看；右键可以打开、在 Finder 中显示、隔空投送、复制（图片多一项「复制图片」）、置顶或移除。
- 图片和 PDF 可以转换：右键图片 →「转换为」JPEG、HEIC、PNG、PDF，或识别图里的文字生成 Word；多张图片可以「合并为一个 PDF」；右键 PDF →「转换为」Word（提取文字）或 PNG / JPEG（每页一张）。右键图片 →「缩小图片」把长边缩到 2560 / 1600 / 800 像素。全部在本机完成，原文件不动，结果排在托盘最前面。
- 就地整理：右键图片 →「压缩到」500 KB / 1 MB / 2 MB / 5 MB 以内；右键 zip、tar、7z、rar →「解压」；右键一个或多个文件 →「重新命名…」，像 Finder 一样替换文字、添加文字或按序号命名，改之前有实时预览，改完可以撤销。
- 文件拖入只记录路径，不复制原文件；原文件被移动或删除后，托盘里会标灰显示「文件已移动」。转换和解压生成的文件存在数据文件夹的 `converted/` 里，在托盘里移除它，文件也一起删除——要长期保留请先拖到别处。
- 清空：页面动作行右边的「清空」只移除这一页里置顶以外的项目，不会删除文件引用指向的原文件，也不会动另一页的内容。
- 自动清理：设置… → 托盘 →「自动清理旧内容」从不 / 1 天 / 7 天 / 30 天，每小时检查一次；「超过 N 天」从项目最近一次放入算起。

## 剪贴板

- 复制过的文字自动收好，并记住来自哪个应用；截图和复制的图片也会进托盘。记录始终开启，没有总开关。
- 按 `⌃⌥V`：「剪贴板」页直接打开、焦点在搜索框，输入即按子串筛选（大小写不敏感），行首是 `⌘1`…`⌘9` 的编号；按编号直接粘贴当前显示顺序的对应项，`↑`/`↓` 选择后回车粘贴选中项。粘贴是完整的：面板收起，键盘回到打开面板前的应用，内容贴进它的输入框，成功时胶囊写「已粘贴」。多选文本按行合并后一起粘贴，文本和图片混选不粘贴、只提示。
- 粘贴需要「辅助功能」权限（与拖拽护栏同一项）。没有权限时 Rakko 不申请、不重置，只把内容放进剪贴板并提示「已复制 · 开启辅助功能后可直接粘贴」，自己按 `⌘V` 即可。目标应用已经退出、或你已经切到别的应用时同样只保留复制，绝不会贴到别的应用里。Esc 先清空搜索、再按一次收起。
- 截图和图片里的文字会在本机识别（一次一张，不联网），也能被搜到；右键图片 →「识别文字并复制」直接复制图中文字。
- 置顶的内容带图钉、排在最前，不被条数限额、自动清理和「清空」移除。不想记录某个应用，右键它的剪贴板条目 →「不再记录来自『应用名』的内容」，它写进 `settings.json` 的 `excludedApps`；也可以在 设置… → 剪贴板 →「排除的应用」里移除。密码管理器标记为隐私的密码不会被记录。
- 保留条数：设置… → 剪贴板 →「保留条数」30 / 100 / 300，默认 30 条文字，单条不限制长度。重复文字移到顶部，不新增重复项；文件和图片不占文字限额。

## 工具页

- 工具页是一张统一的网格：动作卡和小组件放在一起。全新安装时正好两行、不用滚动：音乐 2×2，保持唤醒和 AI 用量各 1×1（AI 用量页关着时这一格是「压缩到 1 MB」），下面是框选文字和打成 zip。其余卡片和小组件（隔空投送、便利贴、最近文件、剪贴板最新等）都在「+」的目录里。已有的布局不变；超过两行时在页内滚动。
- 只有真的把文件拖过面板时，不能处理的动作卡才变暗；转换进行时，动作卡变暗、点按没有反应。小组件和固定到桌面的卡片保持原样。
- 点按动作卡：对托盘里选中的、它能处理的项目执行；也可以把文件直接拖到卡片上。点「便利贴」卡片打开它的窗口，点「AI 用量」卡片进入 AI 用量页，点音乐卡片本身（不是卡片上的按钮）进入首页。
- 编辑：长按任一卡片约半秒，或点动作行右边的铅笔图标。拖动排序、点 ⊖ 移除、拖右下角把手在 1×1 / 2×1 / 2×2 之间切换、点虚线「+」格从目录添加。点「完成」或按 Esc 结束。布局存在 `layout.json`。
- 固定到桌面：编辑时把卡片或小组件拖出面板，它变成桌面上的一张小浮窗，照样可以点按、接收文件。松在屏幕左右边缘附近会收成一条窄条，鼠标移上去展开，移开 0.6 秒后收回，拖着文件靠近也会展开；右键有「始终展开」「放回刘海」「从桌面移除」，拖回刘海也会放回原来的格子。

## 便利贴

- 「便利贴」是工具页的一张卡片（默认不在网格里，在「+」目录中）。点一下打开一块 320 × 380 的窗口：纯 Markdown，第一行（去掉 `#` 和空格）就是标题，停止输入 400 毫秒后自动保存——没有保存按钮，也没有「已保存」提示。Esc 关窗口；没有未保存的输入时，别的编辑器改了文件这里也会跟着更新。
- 窗口顶栏有「在访达中显示」「置顶」「关闭」；标题跟着第一行实时变化。
- 卡片跟着便利贴走：1×1 是图标和名字，2×1 是标题加前三行预览。
- 搜索：在搜索条里输入，「便利贴」一组列出文字相符的便利贴，回车把它在窗口里打开；标题命中的排在正文命中之前，正文命中会带上相符的那一行。
- 文件存在数据文件夹的 `notes/` 里，一个便利贴是一个 Markdown 文件，`notes/current` 记住卡片正在编辑哪一个。

## AI 用量

在 设置… →「AI 用量」→「在刘海里显示 AI 用量」打开（默认关闭），顶栏会多出一个页面图标。

- 整页一屏看全，不用滚动：左栏是 Claude Code、Codex 的套餐额度卡，每张卡内外双圈（外圈每周、内圈 5 小时）；右栏是这台电脑上的 token 用量总量——今天 / 7 天 / 30 天 / 全部，四个数字（Token、请求、费用、缓存命中）和一根合计柱图。
- 悬停额度卡：套餐名、重置时间、每个窗口的用量条和均匀消耗标记，套餐有按模型的每周额度时也在这里列出。悬停 Token 或费用数字：它的组成部分（输入、输出、缓存）。
- 额度默认显示「已用」；设置… →「AI 用量」→「额度显示」可以改成「剩余」。同一页的「套餐额度」组里，Claude Code 和 Codex 各有一个开关，可以单独关掉某张卡。
- Claude Code 的额度由 Claude Code 自己给出：Rakko 运行你装好的 Claude Code 的 `/usage` 命令，所以数字和重置时间与 Claude Code 显示的一致。没装 Claude Code 时卡片会说明；Rakko 不会替你下载。Codex 的额度读取 Codex 保存在本机的登录信息（`~/.codex/auth.json`），只发给 chatgpt.com。
- 打开这一页或点刷新时查询额度（Claude Code 最多 30 秒查一次）；页面一直开着时，只有你用过 Claude Code 才会每 5–15 分钟再查一次。上次的结果存在 `quotas.json`，重启后打开就能看到。
- 本机用量自己去找：omp、Claude Code、Codex、pi、opencode、Grok 的会话记录在它们自己的位置被读取，再加成一个总数。没有按工具拆分，也没有逐个工具的开关；统计缓存存在 `usage-cache/`，删掉只是下次统计变慢。
- 工具页的 AI 用量卡用同一份额度数据：1×1 只画一个双圈，中间是剩余额度最少的那个工具的标志，悬停看数字；2×1 是圈在左、名字在右。

## Agent 完成提醒

设置… →「AI 用量」→「Agent 完成提醒」→「完成时在刘海提醒」，默认关闭。

- 打开后，Rakko 会在它检测到的每个 agent 的配置文件里写入一条 hook（带自己的标记），让「这一轮做完了」传到刘海；关掉时把写进去的条目整条移除。解析不了的文件绝不会被改写。
- 检测只看工具自己写出来的文件（会话目录、登录文件等），安装器留下的空文件夹不算。设置页只列出检测到的工具，每行写着工具名、它自己的配置文件路径，以及 Rakko 的条目是「已注入」「未注入」「不支持」还是「出错」。
- 提示是刘海下面的一张两行卡：第一行是工具的标志、名字和绿色的「完成」，第二行是它刚才在做的事。同一会话两秒内的重复报告只算一次。它只负责通知——不批准、不回复、不读对话。
- Codex 要你自己确认一次：在 Codex 里打开 `/hooks`，审阅 Rakko 加的那条 hook 并信任它；在那之前 Codex 会跳过它。
- 需要安装版：从终端直接运行或 `go run` 的构建不会写入任何东西，设置页会写「需要从安装的 Rakko.app 运行」。

## 桌宠

- 海獭站在桌面上陪着你。拖它可以放到任何地方，靠近 Dock 或屏幕左右边缘会自动站好（贴边）；每块屏幕分别记住位置，重启后还在。拖到刘海上就是「收进刘海」。
- 点它一下打开面板；右键有「打开 Rakko」「收进刘海」「大小」小 / 中 / 大、「设置…」。
- 把文件或文字拖到它身上，就和平常放进刘海一样收进托盘，海獭会把刚接到的东西抱一会儿。平时它只换姿态：站着；有东西悬在它上面时抬起爪子；被你拎着时被拎起；有拖拽经过屏幕时吓一跳；安静十分钟后打瞌睡。它不会到处走动。
- 设置… →「外形与提示」→「桌宠」：「显示海獭」和「大小」。收进刘海后，右键菜单栏图标 →「放出海獭」让它回来。没有海獭图片的构建不显示它，也不显示这一组设置。

## 保持唤醒

右键菜单栏图标 →「保持唤醒」：30 分钟 / 1 小时 / 2 小时 / 4 小时 / 一直（直到关闭）。这段时间里 Mac 不会因为空闲自动睡眠；勾选「屏幕也保持亮着」后屏幕也不会熄灭。开启期间，打开任何一页都能在顶栏看到月亮图标：鼠标停上去看剩余时间，点一下结束。时间到、关闭或退出 Rakko 后恢复正常睡眠；重新打开时默认是关闭的。

## 实时活动

- **充电提示**：插上电源时刘海向两边变宽几秒，左边是闪电图标，右边绿色电量条和电量数字。充满时提醒一次；不插电时电量降到 20% 和 10% 各提醒一次。
- **耳机连接提示**：蓝牙耳机或音箱连上时显示名字和对应型号的系统图标；系统给出各部件电量时，左耳、右耳和充电盒各有一个图标、一圈电量环和百分比，电量 20% 及以下时电量环变红；断开时也会提示一次。鼠标、键盘不提示。
- **下载进度**：浏览器往「下载」文件夹下载时，刘海显示进度环和百分比（不知道总大小时显示已下载多少）；下载完成后点一下提示，文件就放进托盘。同时下载完的几个文件合成一条提示，点一下全部放进托盘。需要「完整磁盘访问」。
- 每一项都可以在 设置… →「外形与提示」→「实时活动」里关掉。

## 灵动岛与拖窗口

- 没有刘海的屏幕（外接显示器等）上，Rakko 总是一颗悬浮的灵动岛：屏幕顶部一颗小黑胶囊，悬停、点开、拖文件进来和各种提示都和刘海一样。有刘海的 MacBook 可以在 设置… →「外形与提示」→「刘海样式」里选「灵动岛」，默认仍是刘海样式。
- 按住小岛可以拖到屏幕任何位置，松手就留在那里，每块屏幕分别记住。展开后的面板自己找位置：下方放得下就向下展开，靠边时和岛错开，下方放不下就向岛上方展开。面板展开时按住顶栏空白处也能拖，整块面板跟着岛走。设置… →「外形与提示」→「灵动岛位置」→「恢复默认位置」回到屏幕顶部。刘海样式不能拖。
- **拖窗口到刘海分屏**：拖着任意窗口的标题栏往刘海走，出现排列面板：左半、全屏、右半、左 1/3、中 1/3、右 1/3。指针停在哪一格就预览窗口会落在哪儿，松手就排好；拖离刘海就取消。需要「辅助功能」权限，可以在 设置… →「外形与提示」→「拖窗口到刘海分屏」关掉。

**settings.json 损坏时**，每一页顶部显示红色提示条，说明设置已按默认值运行，并且偏好控件全部锁定（置灰、点不动），避免把坏文件覆盖成一份看似正常的默认设置；系统权限、关于页和只读的按键说明照常可用。

## 自动更新

正式版 Rakko 会自己检查新版本：启动后约 10 秒查一次，之后每天一次，查询对象是本项目在 GitHub 的最新 Release。发现新版本不会弹窗：菜单栏图标的右键菜单多出「安装更新（vX）…」，只有你选择它才会下载并替换应用。装好后菜单项变成「重新启动 Rakko 完成更新」，设置… → 通用 →「更新」里出现「重新启动」按钮，面板底部的小胶囊也会提示，并给出同样的重新启动。更新包附带数字签名，安装前会验证签名与完整哈希。

不想让它联网检查：设置… → 通用 → 关闭「自动检查更新」，立即生效；关闭后仍可用右键菜单的「检查更新…」或设置里的「现在检查」手动查询。

## 数据与隐私

数据保存在：

```text
~/Library/Application Support/Rakko/
  state.json        托盘内容（含图片清单）
  settings.json     设置
  layout.json       工具页的卡片和小组件排列、桌面固定项的位置
  notes/            便利贴（Markdown）和 current（卡片正在编辑哪一个），用到才有
  images/           剪贴板图片与截图
  converted/        转换和解压生成的文件
  quotas.json       最近一次查到的套餐额度
  usage-cache/      本机 token 用量统计缓存（开启过才有）
  agent.sock        Agent 完成提醒的本地 socket（开关打开时才有）
  .lock             防止同时运行两个 Rakko 的锁文件，运行时不要删除
```

在 Finder 按 `⌘⇧G`，粘贴 `~/Library/Application Support/Rakko/` 即可找到它。备份时先退出 Rakko，再复制整个文件夹；恢复时同样先退出。

同一时间只能运行一个 Rakko：再打开第二个时会提示“已在运行”并立即退出。如果保存的数据无法读取，Rakko 会提示原因；确认后本次启动退出，不会用空内容覆盖原文件。

**不上传任何内容**：没有云同步、遥测或统计。联网请求只有三类：

1. 检查更新：向 GitHub 询问最新版本，请求里只带标准的 User-Agent（应用名和版本）。
2. 可选的 AI 用量页额度查询：Codex 的额度用本机保存的登录信息发给 chatgpt.com；Claude Code 的额度通过运行你装好的 Claude Code 读取，由 Claude Code 自己照常联系 Anthropic。
3. 首页歌词：只有你用首页播放器左下的歌词按钮打开歌词栏后，才把一首还没有结果的歌的歌名、歌手、专辑和时长发给 lrclib.net 查歌词；lrclib.net 没有或太忙时，再把歌名和歌手发给网易云音乐（music.163.com）。查到或确认没有后结果存在本机，不再重复查；收起歌词栏就不再联网。

这三类请求都按同一个代理规则走：

- 启动 Rakko 时带了 `HTTP_PROXY`、`HTTPS_PROXY` 或 `NO_PROXY` 就完全按它们走，与 Go 的标准行为一致（小写变量优先，`NO_PROXY` 支持域名后缀、IP、CIDR 和 `*`）。只设了 `NO_PROXY` 也算设置了：它只表示绕开哪些地址，不会退回系统代理。
- 没有这些变量时用 系统设置 → 网络 → 代理 里的 HTTP、HTTPS、SOCKS 代理，HTTPS 走 HTTPS 代理（没有就用 HTTP 代理的 CONNECT），其余的走 SOCKS；系统例外列表与本地地址（127.0.0.1、localhost）不走代理。系统设置最多每两秒读一次，改完不用重开 Rakko。
- 自动代理配置脚本（PAC）和自动发现不解析：只配了 PAC 时按直连处理，日志里会写明一次。需要 PAC 的场景请改用系统级 VPN，或者显式设置上面三个环境变量。

Agent 完成提醒不增加任何流量：那些 hook 只在本机运行 Rakko 自己的可执行文件，把工具自己的事件通过 `agent.sock` 交给它；它们只报告「这一轮做完了」和这一轮在做什么，不读对话，也不回话。

本机用量只读这台电脑上的会话记录做汇总，统计结果不上传。

**文字历史以明文保存，不提供加密。** 密码管理器标记为隐私的密码不会被记录，但其他复制的内容（验证码、客户资料等）都可能被收进历史。不希望某段内容被记录时，先退出 Rakko 再复制。删除文件引用不会删除你的原文件；在剪贴板页移除剪贴板图片会清理 Rakko 自己保存的图片。

**框选文字**需要「屏幕录制」权限，只在你使用它时才会提示；它只截取你框选的那一块，文字在本机识别，截图不保存、不上传。授权后要退出并重新打开 Rakko 才生效。

各种偏好存在 `settings.json` 里：`"clipboardLimit"`、`"retentionDays"`、`"excludedApps"`、`"autoCheckUpdates"`、`"lyrics"`（`enabled`，首页歌词栏是否打开）、`"removeAfterDrag"`、`"snapWindows"`、`"language"`、`"aiUsage"`（`enabled`、`quotaCodex`、`quotaClaude`、`quotaLeft`）、`"agentNotify"`、`"liveActivities"`、`"pet"`（`shown`、`size`）、`"pinnedApps"`（按顺序保存最多四个应用标识；空数组表示全部取消固定）和 `"shortcuts"`（`toggle`、`clipboard`、`capture`、`tray`、`playPause`、`previous`、`next`、`tools`、`usage`、`awake`、`note`、`pet`、`appSwitch`，空字符串表示这一项没有快捷键）。改完重启 Rakko 生效；文件写错时，Rakko 会提示并按默认设置运行，不会改动你的文件。

## 修改快捷键与灵敏度

十三个全局快捷键在 **设置… → 快捷键** 里改，不用重新打包，分三组：

- **全局快捷键**：显示 / 收起 `⌃⌥Space`、剪贴板搜索 `⌃⌥V`、打开托盘、应用切换（后两项未设置）。
- **播放**：播放 / 暂停、上一首、下一首（都未设置）。
- **工具**：框选文字 `⌃⌥O`、打开工具页、打开 AI 用量、保持唤醒开 / 关、新建便利贴、放出 / 收回海獭（除框选文字外都没有默认值）。

点一下那一行，按下新的组合键就保存并立即生效。带 ⌃、⌥ 或 ⌘ 的组合直接保存；F1–F12、方向键、Home、End、PageUp、PageDown、Insert 可以单用，也可以加 ⇧；会打字的键（字母、数字、标点、空格、Tab、回车）先问一句「X」会在所有应用里被截走，选「仍然使用」或「取消」。Delete 清空这一项，Esc 取消；组合被别的应用占用时，这一行显示「已被占用」，原来的组合照旧。

页面已经打开时，再按剪贴板搜索、打开托盘、打开工具页或打开 AI 用量，就收起面板。AI 用量页关着时，按「打开 AI 用量」打开 设置… →「AI 用量」。Esc 和搜索框里的按键属于面板本身，不能改：「在刘海里」一组只读，Esc 是返回 / 收起，↑ / ↓ / ↩ 在剪贴板里选择并复制。

灵敏度（投放带、悬停余量、离开后多久收起）仍是编译期常量，要改需要改源码后自己重新打包（需要 Go 1.27 或以上以及 Xcode Command Line Tools）。

1. 下载本项目源码，用代码编辑器打开 `cmd/rakko/config.go`。
2. 可以调整：`dropBandPadX`（投放带相对刘海的水平外扩，默认 24pt）、`guardDropPad`（投放带比菜单栏向下多出的高度，默认 16pt）、`notchHoverPadX` / `notchHoverPadY`（空手悬停刘海的感应余量，8 × 4 pt）、`edgeLeaveDelay`（离开后多久收起，350 毫秒）。
3. 在终端进入项目目录，运行：

```sh
go run github.com/egoist/mygo/cmd/mygo build
```

4. 打包好的 `Rakko.app` 和 `.dmg` 在 `dist.noindex/darwin-arm64/` 里。先退出正在运行的 Rakko，再用新的替换。
